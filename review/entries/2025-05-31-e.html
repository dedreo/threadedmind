### 🧱 If it's not deployed yet, here are the simplest deployment options:
#### 1. GitHub Pages (Free)
Good for simple static React builds.
- In your project:
- Run `npm run build` to create a `dist` or `build` folder.
- Install `gh-pages` with:
```bash
npm install --save-dev gh-pages
```
- Add this to your `package.json`:
```json
"homepage": "https://xxx.github.io/Icepickv2",
"scripts": {
"predeploy": "npm run build",
"deploy": "gh-pages -d dist"
}
```
(Replace `dist` with `build` if that’s what your Vite/React app outputs)
- Then run:
```bash
npm run deploy
```
- GitHub → Repo → Settings → Pages
Set the source to the `gh-pages` branch and root folder.
- Wait a moment and check:
➤ `https://xxx.github.io/Icepickv2`
#### 2. Netlify or Vercel (Easy 1-click setup)
Great for React apps and CI/CD.
- Go to [https://netlify.com](https://netlify.com) or [https://vercel.com](https://vercel.com)
- Link your GitHub repo
- Follow the deployment prompts:
- Framework: React / Vite
- Build command: `npm run build`
- Output folder: `dist` or `build` (depending on your project setup)
They’ll give you a live URL like:
`https://icepickv2.netlify.app` or `https://icepickv2.vercel.app`

Google’s search doesn't support full wildcard inside quotes the way you'd expect (like `"It's * cat's and dog's"`), but there are workarounds:
---
### 🔍 1. Use `AROUND(n)` operator (proximity search)
```plaintext
"it's" AROUND(3) "cat's and dog's"
```
This tells Google to find pages where "it's" appears within 3 words of `"cat's and dog's"` — in any order or phrasing. Tweak the number as needed.
✅ Example:
```plaintext
"it's" AROUND(5) "cat's and dog's"
```
---
### 🔍 2. Try multiple partial phrase quotes
If you want variations of the phrase that start with “it’s” and end with “cat’s and dog’s,” break it into pieces:
```plaintext
"it's" "cat's and dog's"
```
This won’t enforce a strict sentence match but will find pages where both parts exist, even with stuff in between.
---
### 🔍 3. Use a site like Google’s Custom Search API or Dataverse tools (advanced)
If you're doing serious linguistic scraping, you’ll need to use structured search tools like:
- Google’s Programmable Search
- Corpus linguistics databases (like COCA or GloWbE)
---
### ⚠️ Google limitations:
- No support for `` wildcards within* quoted phrases.
- `AROUND()` only works on web search, not in News or Books.
- Search is case-insensitive and tends to autocorrect.
---
So for your case:
```plaintext
"it's" AROUND(5) "cat's and dog's"
```
is your best bet for finding things like:
