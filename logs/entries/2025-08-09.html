# High-impact backend add-ons for Wmcy

**1) Model lifecycle + VRAM controller**
- Endpoints: `POST /model/load`, `POST /model/unload`, `GET /gpu/stats`
- Impl: shell out to `nvidia-smi --query-gpu=memory.used,memory.total --format=csv,noheader,nounits` (or NVML bindings) + keep a registry of which engines (Mistral, embedders, SD) are “hot.”
- Policy: auto-evict least-recently-used model when VRAM > threshold; optional “pinned” models that never unload.

**2) Router that picks the right engine per prompt**
- Endpoints: `POST /route`
- Rules look at: mode (General/Debug/Narrative/X), token estimate, tools requested, latency target.
- Example: Narrative → bigger context LLM; Debug → faster low-latency model; Summarize → small cheap model.

**3) Tool sandbox + capability broker**
- Unified `POST /tools/run` that dispatches whitelisted tools (file read, grep vault, math, web fetch, image gen).
- Each tool is a separate process with a time+IO budget; log every tool call for the Event Log.
- Prevents your UI or model from touching the system outside allowed paths.

**4) Memory layer that isn’t dumb**
- Short-term convo store (SQLite) + long-term facts (JSON/SQLite) + vector index for “fetch-what-matters.”
- Endpoints: `POST /mem/upsert`, `POST /mem/summarize`, `POST /mem/pin`, `GET /mem/search?q=...`
- Policy: periodic auto-summarize long threads, pin manual highlights from UI.

**5) Obsidian vault indexer (read-only, like you planned)**
- Watcher pipeline: on file change → extract frontmatter → chunk → embed → store to `/mem`.
- Endpoints: `POST /vault/reindex`, `GET /vault/search`
- Lets X-Mode load context by filename or tag without you dragging files every time.

**6) Prompt/template registry (source of truth)**
- Endpoints: `GET/PUT /prompts/:id`, `GET /prompts?mode=Debug`
- Store system prompts, persona blurbs, guardrails, and per-mode defaults. UI toggles just switch IDs, not raw text.

**7) Request queue + rate governor**
- Endpoints are enqueued; concurrency per model/tool; backpressure if GPU is saturated.
- Prevents “one spammy click” from thrashing VRAM.

**8) Circuit breakers + retries**
- If a model/tool fails N times in M minutes → open circuit; route to fallback or return a crisp error.
- Timeouts on generation + tool calls so the UI never hangs.

**9) Structured logging + timeline**
- Every turn: {prompt id, tool calls, tokens in/out, latency, VRAM snapshot}.
- Endpoints: `GET /events?since=...`, `GET /metrics`
- Your right-side “Event Log” pulls directly from this.

**10) Token/latency estimator before send**
- `POST /estimate` gives token count + cost + projected latency so the UI can warn when a prompt will blow context.

**11) Response post-processor**
- Normalizes outputs: adds headings for Narrative, adds code fences for Debug, trims repetition.
- Keeps UI consistent across models without hacking every component.

**12) Cache**
- Hash(input+tool) → response cache with short TTL (e.g., summaries of the same pasted text).
- Also cache embeddings for identical files/chunks.

**13) Job runner (local “cron”)**
- Jobs: nightly vault re-index, memory compaction, avatar metadata refresh.
- Endpoint: `POST /jobs/run/:name` for manual kicks from the UI.

**14) Persona/mode state server**
- `GET/PUT /session/state` holds: active mode, active avatar, current system prompt id, feature flags.
- Lets all modes share truth without prop-drilling chaos.

**15) Minimal security wall**
- Local token, CORS locked to your app origin, and explicit allow-lists for filesystem and network tools.

```js
// src/services/modelRegistry.js
const models = new Map(); // name -> { loaded:bool, lastUsed:number, sizeMB:number, pinned:boolean }

export async function loadModel(name, loader, { sizeMB=4500, pinned=false } = {}) {
let m = models.get(name) || { loaded:false, sizeMB, pinned:false, lastUsed:0 };
if (!m.loaded) await loader(name);
m.loaded = true; m.pinned = pinned; m.lastUsed = Date.now(); m.sizeMB = sizeMB;
models.set(name, m);
return m;
}

export async function unloadModel(name, unloader) {
const m = models.get(name);
if (!m || !m.loaded) return;
await unloader(name);
m.loaded = false; m.lastUsed = Date.now();
models.set(name, m);
}

export function markUsed(name) {
const m = models.get(name);
if (m) { m.lastUsed = Date.now(); models.set(name, m); }
}

export function listLoaded() {
return [...models.entries()].filter(([_, m]) => m.loaded).map(([name, m]) => ({ name, ...m }));
}

export function pickEviction() {
const loaded = listLoaded().filter(m => !m.pinned);
if (!loaded.length) return null;
loaded.sort((a,b) => a.lastUsed - b.lastUsed);
return loaded[0].name;
}
```

```js
// src/middleware/queue.js
const MAX_CONCURRENCY = 2;
let inFlight = 0;
const pending = [];

export function queued(handler) {
return async (req, res, next) => {
const task = () => handler(req, res, (e) => {
inFlight--; kick();
if (e) next(e);
});
pending.push(task);
kick();
};
}

function kick() {
while (inFlight < MAX_CONCURRENCY && pending.length) {
const t = pending.shift();
inFlight++;
t();
}
}
```

### How to use (sheet cells)

```vba
Option Explicit

Private Function JsonEscape(ByVal s As String) As String
s = Replace(s, "\", "\\")
s = Replace(s, """", "\""")
s = Replace(s, vbCrLf, "\n")
s = Replace(s, vbCr, "\n")
s = Replace(s, vbLf, "\n")
JsonEscape = s
End Function

Private Function HttpPost(url As String, payload As String, Optional apiKey As String = "") As String
Dim xhr As Object
Set xhr = CreateObject("MSXML2.XMLHTTP")
xhr.Open "POST", url, False
xhr.setRequestHeader "Content-Type", "application/json"
If Len(apiKey) > 0 Then xhr.setRequestHeader "Authorization", "Bearer " & apiKey
xhr.send payload
HttpPost = xhr.responseText
End Function

' =LLM_OLLAMA("your prompt", "http://localhost:11434/api/generate", "mistral:instruct")
Public Function LLM_OLLAMA(prompt As String, endpoint As String, model As String) As String
On Error GoTo fail
Dim body As String, resp As String
```

```vba
Option Explicit

Private Function JsonEscape(ByVal s As String) As String
s = Replace(s, "\", "\\")
s = Replace(s, """", "\""")
s = Replace(s, vbCrLf, "\n")
s = Replace(s, vbCr, "\n")
s = Replace(s, vbLf, "\n")
JsonEscape = s
End Function

Private Function HttpPost(url As String, payload As String, Optional apiKey As String = "") As String
Dim xhr As Object
Set xhr = CreateObject("MSXML2.XMLHTTP")
xhr.Open "POST", url, False
xhr.setRequestHeader "Content-Type", "application/json"
If Len(apiKey) > 0 Then xhr.setRequestHeader "Authorization", "Bearer " & apiKey
xhr.send payload
HttpPost = xhr.responseText
End Function

' =LLM_OPENAI("your prompt", "http://localhost:3000/v1/chat/completions", "my-model", "sk-LOCAL-OPTIONAL")
Public Function LLM_OPENAI(prompt As String, endpoint As String, model As String, Optional apiKey As String = "") As String
On Error GoTo fail
Dim body As String, resp As String
body = "{""model"":""" & JsonEscape(model) & """,""messages"":[{""role"":""user"",""content"":""" & JsonEscape(prompt) & """}],""stream"":false}"
resp = HttpPost(endpoint, body, apiKey)

' crude parse: choices(0).message.content
Dim i As Long
i = InStr(1, resp, """content"":", vbTextCompare)
If i > 0 Then
i = InStr(i + 10, resp, """") + 1
Dim j As Long: j = InStr(i, resp, """")
If j > i Then
LLM_OPENAI = Replace(Mid$(resp, i, j - i), "\n", vbLf)
Exit Function
End If
End If
LLM_OPENAI = resp
Exit Function
fail:
LLM_OPENAI = "#ERR " & Err.Description
End Function
```

## Notes that’ll save you pain
- **No streaming** in these UDFs (by design). Excel UDFs block until the HTTP call returns; streaming would make a mess.
- **JSON parsing is minimal** to keep it simple. If you want robust parsing, add a VBA JSON module (e.g., `JsonConverter.bas`) and read `choices(1).message.content` properly.
- **Mac:** replace `MSXML2.XMLHTTP` with `MSXML2.ServerXMLHTTP` or use `WinHttp.WinHttpRequest.5.1` if available. Macs sometimes need `Application.Volatile False` + careful timeouts.
- **Drag-to-fill:** these are pure functions, so you can fill down a whole column (`=LLM_OLLAMA("capital of " & B2, $B$1, $B$2)`).
- **Guardrails:** huge prompts will freeze Excel while the request runs. Keep input short or run on smaller batches.

If you want to hit **your Wmcy backend** instead, just point the endpoint to your `/route` (mode-aware) or add a tiny wrapper route like `/excel` that forwards the prompt and returns plain text.
