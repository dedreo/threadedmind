| Core Type | Count | Use Case |
|------------|-------|-------------------|
| P-cores | 8 | Fast, heavy work |
| E-cores | 8 | Light background |
| Hyperthreads | yes | 24 threads total (8P + 8E + HT) |

But **E-cores** are slow for LLM inference. So **stick to physical P-cores** for max throughput.

---

## ✅ **Recommended Thread Setting**
```bash
--threads 8
```

That tells KoboldCpp:
- Use the **8 Performance cores**
- Ignore the Efficiency cores and hyperthreads (which don’t help much here)

If you're multitasking or want to leave some CPU headroom (for e.g. Discord, coding, or streaming):
```bash

```

If you're benchmarking or running this as a dedicated box:
```bash

```

Beyond that, you hit diminishing returns.

1. **Training** = teaching the model.

### **What actually happens during inference?**

Every time you send a prompt, the model does this:

- Takes your input (`"Tell me a story about..."`)
- Converts it into **tokens** (basically: compressed numbers)
- Feeds those tokens into the model
- The model processes the tokens layer by layer
- It *predicts* the next most likely token... then the next... and the next...
- Those predictions get turned back into words/sentences
- You see the output

All of that = **inference.**

---

If training is building a brain,
**inference is using that brain to answer questions**.
