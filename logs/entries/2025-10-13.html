## 🧠 What is Swap (and Do You Need It)?

**Swap** is disk space used like RAM *when* you run out of actual RAM — much slower, but it prevents crashes or out-of-memory errors.

---

## 🧮 General Swap Guidelines

| RAM Amount | Swap Needed? | Notes |
|------------|--------------|-------|
| < 4 GB | ✅ Yes | Required for stability |
| 4–8 GB | ✅ Recommended | For hibernation, big tools, or low-memory systems |
| 16+ GB | ❌ Optional | Only needed in edge cases (e.g., big memory leaks or hibernation)

---

## 🔌 But What If...

| Use Case | Need Swap? | Why |

| **Running heavy memory tools** | Maybe | Memory dumps, brute force wordlists, etc. |
| **Just learning Kali, scanning, doing small tests** | ❌ No | 16 GB is overkill for most tasks |

- a scheduled task
- a background service

- a tampered update path
