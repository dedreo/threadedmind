### 🎮 **How AI Opponents Typically Work in Puzzle Games like Tetris/Icepick**

At its core, the AI needs to:
1. **Analyze the current board state**
2. **Simulate legal moves for the current piece**
3. **Score each move based on heuristics**
4. **Pick the best (or semi-best) move**
5. **Act at a controlled pace**

And you can tweak that flow to create **difficulty levels**.

---

### 🧠 Example: AI Logic Tiers for Icepick

#### **Easy AI**
- Picks from a few random *valid* moves
- Ignores future pieces
- Might intentionally delay or make suboptimal placements

#### **Medium AI**
- Evaluates board height, line clears, and blob traps
- Picks highest-scoring move from a limited evaluation
- Has simple tactics like “don’t stack too high”

#### **Hard AI**
- Simulates multiple pieces ahead (like chess depth)
- Calculates combos, clears, and blob chain effects
- Actively tries to sabotage opponent via powerup timing

---

### 🛠️ Technically, how do you “adjust” difficulty?

You build the AI like a decision-making function:

```js
function chooseMove(matrix, piece, level) {
const possibleMoves = simulateAllRotationsAndPositions(piece);

let scoredMoves = possibleMoves.map(move => ({
move,
score: evaluateBoard(matrix, move, level)
}));

// Easy mode: pick randomly among top 3
if (level === 'easy') {
return randomPick(scoredMoves.slice(0, 3));
}

// Medium: pick the best
if (level === 'medium') {
return scoredMoves.sort((a, b) => b.score - a.score)[0];
}

// Hard: deeper evaluation (could include looking ahead)
if (level === 'hard') {
return deepSearch(matrix, piece);
}
}
```

You don’t need to rewrite AI logic per level — you just **change what it values and how “deep” it thinks**.

- Let it “misclick” rarely on easy
- Make it respond to your player actions (e.g., speeds up if you're dominating)
