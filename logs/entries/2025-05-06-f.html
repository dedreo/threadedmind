Assistant
To load a saved UI layout in **Dungeons & Dragons Online (DDO)**:

### ✅ **Use this command in the chat box**:
```
/ui layout load [name]
```

Where `[name]` is the filename you saved earlier **without the `.dat` extension**.

---

### Example:
If you previously saved your layout with:
```
/ui layout save mycoollayout
```
Then to load it back, you'd type:
```
/ui layout load mycoollayout
```

---

### A few extra notes:
- You can keep multiple UI profiles this way — useful for switching between melee, caster, and ranged layouts.
- UI layouts are saved in your **Documents → DDO folder**, usually as `.dat` files.
- If it doesn’t work, make sure the name is spelled *exactly* the same as the one you saved.
