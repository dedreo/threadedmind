Assistant
Yep! You can use [The Cat API](https://thecatapi.com/) for a random cat image generator. It works similarly to the Dog API your class is using. Here's a simple fetch request you can use:

```javascript
fetch("https://api.thecatapi.com/v1/images/search")
.then(response => response.json())
.then(data => {
const img = document.createElement("img");
img.src = data[0].url;
img.alt = "Random Cat";
document.body.appendChild(img);
})
.catch(error => console.error("Error fetching cat image:", error));
```

This will grab a random cat picture and display it. If your project already handles the Dog API, you should just be able to swap out the URL and adjust how the response is structured.


```css
#catImg {

height: 300px;
object-fit: cover; /* Optional: maintains aspect ratio and ensures the image covers the area without distortion */
}
```

You can replace `300px` with whatever size you prefer.

- `object-fit: cover;` ensures that the image maintains its aspect ratio while filling the designated space without stretching. If you want the image to be stretched or distorted to fit the box, you can omit that line.
