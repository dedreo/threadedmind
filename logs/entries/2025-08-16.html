Yep, super quick and dirty fix with dev tools:

1. **Right-click the table** → choose **Inspect** (or hit `F12`).
2. In the Elements panel, hover until you see the `<table>` (or sometimes a wrapper `<div>`).
3. In the **Styles** pane on the right, add a rule like:
```css
width: 100% !important;
max-width: 100% !important;
table-layout: auto !important;
```
4. If it’s in a container that’s locked, apply the same to that parent `<div>`.

That forces the table to stretch with your screen instead of staying fixed.

For something even lazier:
- In the console (`F12` → Console tab), paste:
```js
document.querySelector("table").style.width = "100%";
```
(replace `table` with a more specific selector if needed).
