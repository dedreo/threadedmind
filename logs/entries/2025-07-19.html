Add a `formatWymcText()` function right above your component or in a helper file:

const formatWymcText = (text) => {

## 🔍 Detecting Speaker Changes

Here’s what we can key off of:
- Dialogue often starts with `“`, `"` or `-` (dash-style)
- Speaker tags like `Bob:`, `AI:`, or `Narrator:` indicate new speakers

We’ll add a formatting rule that looks for those patterns and separates them cleanly.

## 🛠 Updated `formatWymcText()` Function

Replace your current version with this:

```js
const formatWymcText = (text) => {
// Break into paragraphs first
return text
.split(/\n{2,}/g)
.map(para => {
// Handle dialog-style speaker tags
const dialogLines = para.split(/\n|(?<!\w)(?=[A-Z][a-z]+:)/g).map(line => {
const trimmed = line.trim();
if (/^[A-Z][a-z]+:/.test(trimmed)) {
return `<div class="ml-4 mb-1"><strong>${trimmed}</strong></div>`;
}
return `<div class="ml-4 mb-1">${trimmed}</div>`;
}).join('');

return `<div class="mb-2">${dialogLines
.replace(/(\*\*.*?\*\*)/g, match => `<strong>${match.slice(2, -2)}</strong>`)
.replace(/(\*.*?\*)/g, match => `<em>${match.slice(1, -1)}</em>`)
.replace(/`(.*?)`/g, '<code class="bg-neutral-900 px-1 py-0.5 rounded">$1</code>')
}</div>`;
})
.join('');
};
```
