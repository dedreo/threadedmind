## 🧠 **What It Is**
A Node.js script is just a `.js` file (like `createSkeleton.js`) that you run with `node createSkeleton.js`. It uses Node’s built-in `fs` and `path` modules to create files and directories.

---

## 🛠️ **How To Use It**

### 1. **Create the script file**

Let’s say you're in your project root folder. Make a new file:

```bash

```

Paste this into it:

```js
// createSkeleton.js
const fs = require('fs');
const path = require('path');

const structure = {
'src/components/CurrentWeather': ['CurrentWeather.jsx'],
'src/components/Forecast': ['ForecastList.jsx', 'ForecastItem.jsx'],
'src/components/SearchBar': ['SearchBar.jsx'],
'src/components/Header': ['Header.jsx'],
'src/components/Layout': ['Layout.jsx'],
'src/components/UI': ['LoadingSpinner.jsx', 'ErrorMessage.jsx'],
'src/services': ['weatherService.js'],
'src/hooks': ['useWeather.js'],
'src/utils': ['helpers.js'],
'src/context': ['WeatherContext.jsx'],
'src/pages': ['Home.jsx', 'Forecast.jsx', 'NotFound.jsx'],
'src/assets/icons/weather-icons': [],
};

Object.entries(structure).forEach(([folder, files]) => {
const fullPath = path.resolve(folder);
if (!fs.existsSync(fullPath)) {
fs.mkdirSync(fullPath, { recursive: true });
console.log(`Created folder: ${folder}`);
}

files.forEach((file) => {
const filePath = path.join(fullPath, file);
if (!fs.existsSync(filePath)) {
fs.writeFileSync(filePath, '');
console.log(`Created file: ${filePath}`);
}
});
});
```

Assistant
TypeScript is a **superset of JavaScript** that adds **static typing** to the language. Essentially, it allows you to declare types for variables, function arguments, return types, and more, helping to catch errors during development (before the code runs) instead of runtime. It’s especially useful for larger projects, teams, and when you want better tooling support (like autocomplete and type-checking).

Here’s a quick comparison:

### JavaScript (No Typing)
```javascript
let message = "Hello";
message = 42; // No error in JS, but it's clearly a problem
```

### TypeScript (With Typing)
```typescript
let message: string = "Hello";
message = 42; // Error: Type 'number' is not assignable to type 'string'.
```

**Key benefits of TypeScript:**
1. **Type Safety**: You define types (e.g., string, number, boolean, etc.), which can prevent bugs by catching type errors early.
2. **Better Tooling**: With TypeScript, tools like VSCode provide better autocompletion, IntelliSense, and error checking.
3. **Scalability**: As your app grows, TypeScript makes it easier to manage large codebases with clear interfaces and type structures.
4. **Optional**: You can opt to use TypeScript in your project gradually; it doesn’t require you to convert everything at once.

### When should you use it?
- **Small projects**: You might prefer regular JavaScript if you're just making small, quick projects.
- **Large projects**: TypeScript is fantastic for larger apps or when working in a team, as it helps prevent common issues and keeps everything more maintainable.

### React + TypeScript
In a React app, TypeScript allows you to specify prop types, state types, and other elements of components, which can make the codebase easier to manage.

Example with TypeScript in React:
```tsx
interface Props {
name: string;
}

const WelcomeMessage: React.FC<Props> = ({ name }) => {
return <h1>Hello, {name}!</h1>;
};
```

In the example above, we define the `Props` interface to specify that the `name` prop should always be a string, making it easier to spot mistakes.
